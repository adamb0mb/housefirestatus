Xfinity outage API — browser CORS test

What this page does: tries to call Comcast's own outage-check API (api.sc.xfinity.com) directly from your browser, the same three-step flow their own statusmap page uses: get an anonymous session token → address lookup → outage data. This page is not hosted on xfinity.com, so the expectation going in is that the browser's CORS policy will block it — Xfinity's session endpoint only allows requests originating from xfinity.com/www.xfinity.com (checked via the actual Access-Control-Allow-Origin response header beforehand). This page exists to confirm that empirically instead of just asserting it, and to show exactly how it fails if it does.
